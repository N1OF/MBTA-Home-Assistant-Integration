# MBTA Departures 0.1.0

Initial community release for Home Assistant covering Boston South Station and North Station.

Includes UI setup, all six service groups, real-time departures with schedule fallback, available tracks, station alerts and an optional black-and-amber departure board.

Install the integration through a HACS custom repository or by copying `custom_components/mbta_departures`. Install the frontend JavaScript separately and register it as a dashboard resource; see README.md.

MIT licensed. Tested locally with parser and frontend logic checks, and reported working in the author's Home Assistant installation. Broader version testing is welcome. Not affiliated with MBTA.
